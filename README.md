# Eaint The Hsu — Portfolio

A responsive portfolio for an environmental science researcher and programme coordination professional.

## Run locally

```sh
npm start
```

Open [http://localhost:3000](http://localhost:3000).

## Included

- Responsive editorial layout for mobile, tablet, and desktop
- Research, programme coordination, stakeholder, and data case studies
- In-site document showcase for the 19-slide portfolio and two-page CV
- Page thumbnails, previous/next controls, and responsive document viewing
- Accessible mobile navigation and project detail dialogs
- Scroll progress, continuous marquee, floating hero, and reveal motion
- Optimised WebP images extracted from the source portfolio
- Downloadable CV and original portfolio PDFs
- Lightweight installable web app shell
